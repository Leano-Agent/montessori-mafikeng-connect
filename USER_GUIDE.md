# Montessori Mafikeng Connect - User Guide

## 📖 Introduction

Welcome to Montessori Mafikeng Connect! This guide will help you navigate and use our educational platform designed specifically for African Montessori schools. The platform supports Setswana and English languages and works both online and offline.

## 🎯 Quick Start Guide

### 1. Access the Platform
- **Web**: Visit `https://montessori-mafikeng.connect` in your browser
- **Mobile App**: Install as PWA (Progressive Web App) from your browser
- **Offline**: Works without internet after initial setup

### 2. First Time Setup
1. **Create Account**: Click "Register" and fill in your details
2. **Verify Email**: Check your email for verification link
3. **Complete Profile**: Add profile picture and preferences
4. **Set Language**: Choose Setswana or English
5. **Connect to School**: Enter school code provided by administrator

### 3. Platform Tour
- **Dashboard**: Your main hub with notifications and quick actions
- **Navigation Menu**: Access all features from the sidebar
- **Notifications**: Bell icon for important updates
- **Language Switch**: Globe icon to change language
- **Offline Indicator**: Shows when you're working offline

## 📱 Mobile App Installation

### Install as PWA (Progressive Web App)
1. Open `https://montessori-mafikeng.connect` in Chrome/Safari
2. Tap "Share" button (iOS) or menu (Android)
3. Select "Add to Home Screen"
4. Name it "Montessori Connect"
5. Tap "Add" - App icon appears on home screen

### Offline Functionality
- Works without internet after first load
- Data syncs automatically when back online
- Critical notifications via SMS if offline

## 🔐 Authentication & Security

### Login
1. Enter your email and password
2. Enable "Remember me" for 30-day login
3. Use biometric login if supported (fingerprint/face ID)

### Password Security
- Minimum 8 characters
- Must include uppercase, lowercase, number, special character
- Change password every 90 days
- Two-factor authentication available

### Session Management
- Automatic logout after 30 minutes of inactivity
- Multiple device support
- View active sessions in settings

### Montessori Observations

#### 1. Recording Observations
1. Select student from roster
2. Choose Montessori area (Practical Life, Sensorial, etc.)
3. Describe the activity
4. Add photos or notes
5. Tag with relevant skills
6. Save observation

#### 2. Observation Types
- **Spontaneous**: Unplanned observations
- **Planned**: Scheduled observation sessions
- **Skill-focused**: Tracking specific skill development
- **Progress check**: Periodic assessment

#### 3. Best Practices
- Observe without interrupting
- Focus on one student at a time
- Use objective language
- Include context and environment
- Note materials used

## 🔧 Technical Support

### Common Issues & Solutions

#### 1. Login Problems
- **Forgot Password**: Use "Reset Password" link
- **Account Locked**: Contact administrator
- **Email Not Verified**: Check spam folder
- **Biometric Fail**: Use password login

#### 2. Offline Issues
- **App Not Working Offline**: Ensure initial online load
- **Data Not Syncing**: Check internet connection
- **Sync Conflicts**: Review and resolve conflicts
- **Storage Full**: Clear cache or contact admin

#### 3. Performance Issues
- **Slow Loading**: Clear browser cache
- **App Crashes**: Update browser or reinstall PWA
- **Missing Features**: Check user permissions
- **Display Issues**: Check browser compatibility
